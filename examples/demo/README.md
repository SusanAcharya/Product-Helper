# Lumen Desk

A calm workspace for writers who want research, drafts, and publishing in one place.

## Users

Independent writers and small editorial teams.

## Problem

Research notes, draft chapters, and publish checklists live in different tools, so nothing ships on time.

## Features

### Research inbox
Capture quotes and sources without leaving the draft.

### Focus editor
A distraction-light editor with chapter outlines.

### Publish checklist
Shared launch steps before a piece goes live.

### Review lane
Editors leave decisions the author must accept.

This folder is a Product-Helper example. Run from the package root:

```bash
node ../../bin/product-helper.js init --dir .
node ../../bin/product-helper.js serve --dir .
```
